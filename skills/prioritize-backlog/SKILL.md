# Prioritize the backlog

1. Pull candidate issues via the tracker MCP. Do not invent a board.
2. Rank by user value, urgency, and dependency — state the rubric you used.
3. Call out items blocked on other teams.
4. Propose a cut line. Confirm before editing ranks or flags.
5. Apply rank fields only after the user confirms, using fields the tracker MCP already exposed.
