# Triage a feature

1. Capture the job-to-be-done in one sentence.
2. If the ask is a bug, switch to `triage-bug`.
3. If the spec is thin, run `clarify-prd` before filing.
4. Search for duplicates and overlapping epics via the tracker MCP.
5. File with `open-work-item` only after confirm.
